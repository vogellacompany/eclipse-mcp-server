Eclipse MCP Server

Turns a running Eclipse IDE into an MCP server, so LLM clients can use its Java model, problem markers, debugger and workbench.

Update site

https://vogellacompany.github.io/eclipse-mcp-server/

Install

  1. In Eclipse, open Help > Install New Software...
  2. Paste the update site URL into Work with and press Enter.
  3. Select Eclipse MCP Server, finish the wizard and restart.

Current build

1.0.0.202610021020

This site carries the newest build and nothing else. The previous build is dropped when a new one is published, so update rather than pin.
